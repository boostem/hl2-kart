# Race music candidates

This is a shortlist of royalty-free tracks that could replace or sit alongside the HL2 score as kart race music.
**Nothing has been added to the repo yet.** These are only links and license notes; no audio was downloaded or committed.
For the HL2 tracks the mod plays today, see `Kart.Music.*` in `game/mod_hl2mp/scripts/game_sounds_kart.txt` and
section 5 of [valve-content.md](valve-content.md).

How to pick:
- **Prefer CC0.** It is a public-domain dedication, so no credit is legally required. The CC0 lines below are a
  courtesy and record where each file came from.
- **CC-BY tracks require credit.** If you use one, add its line from "License lines" to `CREDITS.md`.
- Open the page again before adding a track and confirm the license, because uploaders can edit pages.
- Tracks marked "loopable" are presented as seamless loops. Several MintoDog tracks also have a faster "Climax"
  version that could play on the final lap.
- To add one: put the file under `game/mod_hl2mp/sound/music/kart/`, add a `Kart.Music.<file name>` entry next to the
  HL2 ones and set the map's `kart_race_manager` `music` keyvalue to it.

Durations are "unknown" where the page lists only file sizes; BPM comes from the file names.
